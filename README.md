# py-basketball

Objectives

- UI in Angular
  - Passing parameters for analysis
  - Viewing data
- Backend in Python
  - Retrieve data for top basketball players from the last 3, 5 and 10 days once per day
- AI Powered analysis for trends and outliers

## Installation

Use the package manager [pip](https://pip.pypa.io/en/stable/) to install.

```bash
pip install -r src/server/requirements.txt
```
